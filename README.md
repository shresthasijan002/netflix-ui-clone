# Netflix UI Clone (Responsive HTML & CSS)

A responsive front-end UI clone of the Netflix landing page built using only **HTML5** and **CSS3**. This project replicates Netflix's dark-themed interface, layout structure, and mobile responsiveness without JavaScript or a backend.

## Features
- **Hero Banner & Header:** Full-width background banner with navigation bar, sign-in button, and email sign-up call-to-action.
- **Feature Sections:** Alternating text-and-media showcase rows highlighting TV, mobile, and offline viewing.
- **FAQ Layout:** Styled frequently asked questions section matching Netflix's visual design.
- **Footer Links:** Multi-column footer navigation with language selector styling.
- **Fully Responsive:** Adapts smoothly across desktop, tablet, and mobile screen sizes.

## Tech Stack
- **HTML5** (Semantic markup)
- **CSS3** (Flexbox, CSS Grid, positioning, media queries)
